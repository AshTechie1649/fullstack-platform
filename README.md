# Full-Stack Platform (MERN + DevOps)

Enterprise full-stack e-commerce architecture built with React, Node.js/Express, MongoDB Atlas, Docker, and AWS CI/CD pipelines.

## Project Structure
- `/client`: React Single-Page Application (Vite + Redux Toolkit + RTK Query)
- `/server`: Layered Node.js/Express REST API (Helmet, Rate Limiting, Centralized Error Handling)

## Getting Started

### Prerequisites
- Node.js >= 18
- npm >= 9

### Installation
```bash
npm install
npm run server  # Boots Express backend with nodemon
